# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : respect, bienveillance, critiques portant sur le code et non sur les personnes. Le harcèlement,
le doxxing, et la publication d'informations personnelles (y compris de participants à des manifestations,
de forces de l'ordre ou de quiconque) sont interdits dans tous les espaces du projet.

Signalements : via les mainteneurs du dépôt (onglet Security → Report a vulnerability pour les cas sensibles).
